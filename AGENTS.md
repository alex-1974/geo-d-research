# Research Repository Rules

This repository contains research and validation evidence for `geo-d`.

- Do not place production API code here.
- Preserve experiment inputs, outputs, provenance, and negative results.
- Record compiler/toolchain versions for reproducible experiments.
- Preserve exact source/probe hashes where they matter.
- Do not silently rewrite historical evidence.
- Production changes belong in `geo-d`.
- A research result becomes production only through an explicit promotion.
